One word describing the boss: **Nitpicker**.

The boss who cares more about the font size than the strategy — the one who
finds the single typo in a forty-page report and holds the whole meeting on
it. Every office has one, every kitchen has one, every warehouse has one.
It is a word colleagues actually use, it lands on its own with no caption,
and it stings because it is true.

## Entry

`main.ts` writes the word `Nitpicker` (9 characters, one word, no trailing
newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back and verifies
it is byte-identical and passes the single-word gate (1–30 characters,
no whitespace). It throws if `MAKEFUN_OUTPUT_DIR` is unset.
